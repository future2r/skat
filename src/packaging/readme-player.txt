Skat
====

Skat für einen Spieler gegen die Computerspieler Ludwig und Richard.
Es wird nichts installiert und nichts im Internet aufgerufen.


Starten
-------

Doppelklick auf "Skat.exe" in diesem Ordner.

Der Ordner muss so zusammenbleiben, wie er ist: Skat.exe braucht die
Ordner "lib" und "runtime" daneben.


Verknüpfung auf dem Desktop anlegen
-----------------------------------

1. Mit der rechten Maustaste auf "Skat.exe" klicken.
2. "Senden an" und dann "Desktop (Verknüpfung erstellen)" wählen.

Danach startet ein Doppelklick auf "Skat" auf dem Desktop das Spiel.


Einstellungen
-------------

Spielstärke und Ton stellt man im Spiel ein: oben rechts auf "Menü"
klicken, dann "Einstellungen ...". Sie werden im Benutzerprofil
gespeichert (%APPDATA%\Skat).


Entfernen
---------

Einfach diesen Ordner löschen, dazu die Verknüpfung auf dem Desktop und
auf Wunsch den Ordner %APPDATA%\Skat.


Systemvoraussetzungen
---------------------

Windows 7 oder neuer, 32 oder 64 Bit. Java muss nicht installiert sein,
es ist im Ordner "runtime" enthalten.
